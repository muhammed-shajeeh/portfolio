# Muhammed Shajeeh M — Portfolio

A responsive, dark-themed personal portfolio made with plain HTML, CSS, and JavaScript. No build tools or backend required.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

For a local development server, you can use VS Code's Live Server extension.

## Personalize before publishing
1. Your email, GitHub, and LinkedIn links are already filled in. Verify that the LinkedIn URL matches your profile.
2. Your resume PDF is included at `assets/resume.pdf`, and the portfolio's Download resume button links to it.
3. Add project repository/demo links when they are ready.
4. Review project descriptions and skill labels to ensure they accurately reflect your current work.
5. Optionally add a professional photo.

## Publish for free
- **GitHub Pages:** upload the files to a repository and enable Pages in repository Settings.
- **Cloudflare Pages:** create a Pages project and deploy this folder as a static site. No build command is required; use the folder as the output directory.
- **Netlify:** drag and drop the extracted folder into its manual deploy area.

## Included
- `index.html` — semantic page content
- `styles.css` — responsive styling and illustrations
- `script.js` — mobile navigation and small page interactions

The site uses Google Fonts when internet access is available; system fallback fonts are provided.
